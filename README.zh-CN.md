# A 股多因子研究

本项目研究一个问题：在现实执行约束下，将价值、动量和低波动率信号组合，能否在
A 股横截面上获得风险调整后的超额收益。

本仓库只发布 V1 研究表面：冻结研究协议、经过筛选的汇总证据和确定性合成软件演示。
许可行情数据、原始证券级面板、本地凭证以及 A 股机器学习/V3 实验均不公开。

英文主文档：[README.md](README.md)

## 研究方法

每月对股票池进行截面排序，使用三个信号：

- `B/M proxy`：历史 PB 的倒数，仅保留 PB 大于零的记录；
- `12-1 momentum`：约十二个月复权价格收益，跳过最近一个月；
- `60-day low volatility`：近期日收益样本标准差的相反数。

每个月对因子进行 1%/99% 缩尾和截面标准化，三因子等权合成，持有 Top-100，
单只股票目标权重上限为 2%。月末收盘形成信号，下一交易日开盘执行。

## 时间切分与研究治理

| 阶段 | 时间 | 用途 |
| --- | --- | --- |
| 研究期 | 2016-01-01 至 2019-12-31 | 因子诊断和组合设计 |
| 验证期 | 2020-01-01 至 2021-12-31 | 冻结规则下的一次性验证 |
| 最终 OOS | 2022-01-01 至 2025-12-31 | 获得授权后执行一次 |

验证期没有用于调参。最终 OOS 使用冻结配置只运行一次。之后的稳健性分析属于
`POST_OOS_ROBUSTNESS`，不能被描述为新的未触碰 OOS。

## 最终 OOS 汇总

基准成本情景为单边 10 bps，数字来自私有许可数据运行后的汇总结果：

| 指标 | 数值 |
| --- | ---: |
| 策略累计收益 | 35.85% |
| 策略年化收益 | 8.29% |
| 相对中证全指年化收益差 | +8.52 个百分点 |
| 零无风险利率夏普 | 0.543 |
| 最大回撤 | -19.81% |
| 年化波动率 | 17.49% |
| 总交易成本 | 449.97 万元 |

同期中证全指累计收益为 -0.85%。2025 年策略收益低于基准，因此不能声称每个年份都
稳定跑赢市场。

详细证据见 [OOS 汇总](reports/oos_summary.md)、[冻结结果报告](reports/oos/p5_result_report.md)
和 [机器可读结果](results/p5_oos/oos_performance.csv)。

## 公开合成演示

公开数据完全虚构且可确定性生成：6 个信号月份、每期 30 只合成证券、共 180 行。
它只验证软件契约，不是正式 OOS 的输入。

```powershell
python -m pip install -r requirements.txt
python scripts/generate_demo_data.py
python scripts/run_public_demo.py
python -m pytest -q
```

公开克隆中，依赖许可数据和冻结私有产物的历史 `test_p*.py` 会默认跳过；具体边界和
维护者显式运行方式见 [data/README.md](data/README.md)。

## 目录说明

- `configs/`：研究规则、成本政策和冻结协议引用；
- `src/`：P1-P6 可复用研究与审计实现；
- `scripts/`：阶段入口和公开合成演示；
- `tests/`：公开契约测试及私有产物验收测试；
- `data/`：数据字典、清单和合成样例；
- `results/`：经过筛选的 OOS 汇总证据；
- `reports/`：方法、OOS、限制和研究报告。

## 主要限制

- `B/M` 是 `1/PB` 代理，并非自行重建的严格 point-in-time book equity；
- 三只退市持仓缺少可审计终止事件，原始结果使用最后可得复权收盘价；
- 四年最终 OOS 不证明容量、实时成交质量或统计显著性；
- 事后稳健性实验不能用于调参或重新选择主策略；
- 合成数据不能复现正式回测，原始和处理后行情数据不会发布。
