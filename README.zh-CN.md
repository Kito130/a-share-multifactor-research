# A 股多因子研究

本项目研究价值、12-1 动量和低波动率三个横截面信号，在现实交易约束下能否形成
具有解释力的 A 股月频组合。研究严格区分研究期、验证期和一次性最终 OOS，并保留
成本、因子失效和数据缺陷等负面证据。

英文主文档：[README.md](README.md)

## 项目概览

| 项目 | 设计 |
| --- | --- |
| 研究问题 | 简单三因子组合经过独立验证、交易成本和执行约束后是否仍有表现 |
| 组合规则 | 月频 Top-100、分数等权、单只目标权重上限 2% |
| 时间切分 | 研究期 2016-2019；验证期 2020-2021；最终 OOS 2022-2025 |
| 执行口径 | 月末形成信号，下一市场交易日开盘成交，先卖后买 |
| 公开边界 | 合成因子面板，以及私有许可数据运行后的有限汇总证据 |

## 因子与组合

```text
B/M 代理(i,t)     = 1 / PB(i,t)，要求 PB > 0
12-1 动量(i,t)    = P_adj(i,t-21) / P_adj(i,t-252) - 1
60 日低波(i,t)    = - 最近 60 个日收益的样本标准差
```

每月对三个因子进行 1%/99% 截面缩尾，再按样本标准差标准化，最后等权合成。
股票需通过上市区间、上市满 120 个交易日、20 日流动性、历史 ST、正 PB、因子完整性
和证券代码历史检查。

验证期只检验预先确定的实现，没有重新调参。最终 OOS 使用冻结配置获授权执行一次。
之后的稳健性分析均属于事后解释，不能用于更换因子、重新选择参数或声称获得新的
未触碰测试集。

回测显式记录佣金与滑点、历史印花税、停牌、开盘涨跌停、失败订单、现金、陈旧估值
以及 `600270.SH` 换股并入 `601598.SH` 的公司行动，但没有建立容量和盘口冲击模型。

## 最终 OOS 证据

基准情景使用单边 10 bps 佣金与滑点，初始资金一亿元。以下为私有许可数据运行后的
汇总证据，不是实盘业绩。

| 指标 | 结果 |
| --- | ---: |
| 累计收益 | 35.8547% |
| 年化收益 | 8.2948% |
| 相对中证全指年化收益差 | +8.5163 个百分点 |
| 零无风险利率夏普 | 0.5434 |
| 最大回撤 | -19.8052% |
| 信息比率 | 0.5444 |
| 双边换手 | 18.4729 |
| 总交易成本 | 4,499,738.44 元，约为初始资金的 4.50% |

同期中证全指累计收益为 -0.8490%，但策略在 2025 年跑输基准。动量因子最终 OOS
平均 Rank IC 为 `-0.02325`、年化 ICIR 为 `-0.5167`。观察结果后删除该因子会把 OOS
变成新的模型选择，因此冻结结果保留这一失败证据。

证据见 [OOS 汇总](reports/oos_summary.md)、
[冻结结果明细](reports/oos/p5_result_report.md)和
[机器可读指标](results/p5_oos/oos_performance.csv)。

## 公开复现

公开样例包含 6 个信号月份、每期 30 只合成证券，共 180 行，所有数据均为虚构。
它只验证因子诊断代码，不能复现正式回测。

```powershell
python -m pip install -r requirements.txt
python scripts/generate_demo_data.py
python scripts/run_public_demo.py
python -m pytest -q
```

## 目录

- `configs/`：研究规则、交易成本和冻结配置；
- `src/`：面板构建、因子研究、回测和审计实现；
- `scripts/`：研究流程入口和公开合成演示；
- `tests/`：公开契约测试及私有产物验收测试；
- `data/`：公开 Schema、数据清单和合成样例；
- `results/`：最终 OOS 的有限汇总证据；
- `reports/`：方法、OOS 汇总、限制和研究报告。

## 主要限制

- `1/PB` 只是 B/M 代理，未自行重建严格 point-in-time book equity，供应商历史修订
  政策尚未完全核验；
- 三只退市持仓缺少可审计的终止估值事件，冻结结果沿用最后可得复权收盘价；
- 四个 OOS 自然年不能证明统计显著性、策略容量或实盘成交质量；
- 合成数据不能支持真实证券结论，也不能复现正式 OOS。
