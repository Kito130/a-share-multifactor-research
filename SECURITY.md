# Security Policy

Do not open a public issue containing API keys, tokens, credentials, private
market data, vendor responses, or complete research reports. Remove the
material locally and rotate any exposed credential first.

For a suspected repository security problem, contact the maintainer privately
through the GitHub account rather than posting the secret or restricted data in
the issue tracker. This repository is a research artifact and does not provide
live trading, investment advice, or a production data-ingestion service.
