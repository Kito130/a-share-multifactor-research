# Synthetic Factor Panel Schema

`data/demo_synthetic/monthly_factor_panel.csv` is a deterministic, fictitious
cross-sectional panel generated by `scripts/generate_demo_data.py`.

| Column | Type | Meaning |
| --- | --- | --- |
| `signal_date` | date | Synthetic month-end signal date |
| `canonical_ts_code` | string | Invented security identifier |
| `industry_code` | string | Invented industry bucket |
| `total_mv_cny` | number | Fictitious market value used by the demo universe rule |
| `universe_eligible` | boolean | Whether the row enters the synthetic cross-section |
| `bm_proxy` | number | Synthetic value-factor observation |
| `bm_proxy_winsorized` | number | Cross-sectionally winsorized value observation |
| `bm_proxy_z` | number | Cross-sectional value z-score |
| `momentum_12_1` | number | Synthetic 12-1 momentum observation |
| `momentum_12_1_winsorized` | number | Cross-sectionally winsorized momentum observation |
| `momentum_12_1_z` | number | Cross-sectional momentum z-score |
| `lowvol_60` | number | Synthetic low-volatility signal, defined so larger is preferred |
| `lowvol_60_winsorized` | number | Cross-sectionally winsorized low-volatility observation |
| `lowvol_60_z` | number | Cross-sectional low-volatility z-score |
| `next_month_return` | number | Fictitious forward return used only for public diagnostics |
| `sample_scope` | string | Must equal `fully_synthetic_software_demo` |

The demo reads only these public fields. It does not load the private daily
panel, code history, corporate actions, orders, holdings, or frozen OOS inputs.
